# FieldProof 360 Pro store pack

This directory contains paste-ready store metadata and compliance declarations for version 1.0.0 of FieldProof 360 Pro.

- [App Store Connect metadata and App Privacy](app-store-connect.md)
- [Google Play metadata and Data Safety](google-play-console.md)
- [Public URLs and launch checklist](public-urls-and-decisions.md)

The declarations are based on the current source tree: local Drift/SQLite storage, camera and photo-library access for report photos, local signatures, Apple/Google store payments, and the RevenueCat Purchases SDK. The public policy, terms, and support destinations are final. Before submission, confirm that no RevenueCat dashboard integrations, customer attributes, or advertising SDKs have been enabled. Those external settings can change the required disclosures.
